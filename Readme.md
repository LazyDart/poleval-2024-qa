## Project Overview

This repository is dedicated to the development of a system for open-domain machine reading comprehension for question answering in Polish, as part of the PolEval 2024 competition. The system will process a question and a paired passage to generate an answer or determine if the question is unanswerable. The project aims to address the challenge of accurately identifying unanswerable questions, a common issue in many language models.

## Key Features

- **Machine Reading Comprehension**: The system leverages advanced language models to understand and extract relevant information from passages.
- **Unanswerable Questions Detection**: Special emphasis on improving the model's ability to recognize when a question cannot be answered based on the given passage.
- **Evaluation Metrics**: Uses Levenshtein edit distance and binary F1 score to evaluate performance.

## Recent Evaluation Results (July 14th, 2024)

The following table presents the performance metrics for different versions of the PLT5 model:

| Model                   | Normalized Levenshtein Distance | Binary F1 Score |
|-------------------------|---------------------------------|-----------------|
| plt5-original-small     | 0.63741              | 0               |
| plt5-original-base      | 0.62649              | 0               |
| plt5-small-2epochs      | 0.35094             | 0.26452 |
| plt5-small-2epochsV2    | 0.37094              | 0.31697  |
| plt5-small-4epochs      | 0.38280              | 0.33230 |
| plt5-small-6epochs      | 0.35144              | 0.33929  |
| plt5-small-8epochs      | 0.32781              | 0.35004 |
| plt5-base-2epochs       | **0.21321**             | 0.34900   |
| plt5-large-2epochs      | 0.23616             | **0.36398** |

- **Normalized Levenshtein Distance**: Calculated between the target texts from the test dataset of PoQuAD and the values generated by different model versions. This metric measures the similarity between the generated and the target text, with lower values indicating higher similarity.
- **Binary F1 Score**: Measures whether the model correctly refrained from answering impossible questions. A higher F1 score indicates better performance in distinguishing answerable from unanswerable questions.


## Installation Instructions

### Local Setup

1. Clone the repository:
    ```bash
    git clone https://github.com/LazyDart/poleval-2024-qa.git
    cd poleval-2024-qa
    ```

2. Install the required dependencies:
    ```bash
    pip install -r requirements.txt
    ```

### Cloud Setup (Google Colab)

1. Open the `9 from Colab Data loading pipeline.ipynb` notebook in Google Colab.
2. Download the PoQuAD dataset manually from [Hugging Face](https://huggingface.co/datasets/clarin-pl/poquad/tree/main).
3. Upload the downloaded data to your Colab instance.
4. Follow the steps in the notebook to preprocess and set up the data.

## Usage Guide

1. **Data Preparation**: Ensure the dataset is properly downloaded and preprocessed.
2. **Model Training**: Use the provided notebooks and scripts to fine-tune the PLT5 models on the training set.
3. **Evaluation**: Validate the models using the development set and evaluate the performance based on Levenshtein distance and binary F1 score.
4. **Testing**: Generate answers for the test sets and format them as required.

## Repository Modules

The repository is organized into several key modules that facilitate data processing, model loading, and evaluation for the Polish question-answering system. The `t5` module is designed to manage the loading and handling of T5 models from Huggingface. It supports both local and Colab environments, ensuring flexibility in development and testing. This module includes functionalities to download and initialize models, adding special tokens necessary for the task, and saving the models for future use.

The `data_processing` module addresses issues with loading the PoQuAD dataset from Huggingface. It provides scripts to manually download, preprocess, and format the dataset, ensuring that data is correctly loaded and prepared for training. This module is crucial for overcoming limitations in the original data loading scripts and provides functions to convert the dataset into a format suitable for model training.

The `eval` module includes tools for evaluating the performance of the trained models. It calculates the Levenshtein distance and binary F1 scores, providing essential metrics for assessing model accuracy and the ability to identify unanswerable questions. 

`data_processing` and `eval` modules are equipped with pytest tests, allowing users to validate the functionality of data processing and evaluation scripts, ensuring the robustness and reliability of the pipeline. To run these tests, simply execute the following command in the repository's root directory:

```bash
pytest
```
